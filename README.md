# Порядок

Умная сортировка папки Загрузки в стиле Liquid Glass для Windows 11.

## Возможности
- Автоматическая сортировка по категориям
- Автосортировка новых файлов
- Переименование с датой
- Автозапуск с Windows
- Отмена последней операции
- Умный журнал активности

## Установка
Скачай ``Poryadok.exe`` из [Releases](../../releases/latest) и запусти.
